# Changelog

## 0.2.1

- Исправлен запуск `yt-dlp`, `ffmpeg`, `ffprobe` и `mpv` из AppImage: дочерние процессы больше не наследуют `PYTHONHOME`, `PYTHONPATH` и библиотечные пути AppImage. Это устраняет ошибку `<no Python frame>` при поиске и воспроизведении.
- Поиск и воспроизведение в AppImage проверены.

## 0.2.0

Крупное обновление: надёжное сохранение, системные интеграции и локальная фонотека.

### Исправления

- Настройки, очередь, библиотека и каталог теперь сохраняются в JSON-файлы в папке данных приложения, а не только в `localStorage`.
- Атомарная запись состояния, восстановление после повреждённого файла, миграция старых настроек из `localStorage`.
- Изображения (фон, частицы, обложки) сжимаются перед сохранением; большие файлы больше не ломают сохранение настроек.
- Исправлено восстановление очереди и позиции трека.
- Исправлены `repeat-one`, ручной переход между треками, повтор трека после окончания, shuffle без повторов.
- Sleep timer теперь реально останавливает воспроизведение.
- Горячие клавиши и их переназначение работают.
- Скорость воспроизведения синхронизирована с настройками.

### Новое

- Локальная фонотека: выбор папок, сканирование метаданных, воспроизведение локальных файлов, поиск.
- Системный трей: показать/скрыть, play/pause, следующий/предыдущий, выход.
- Автозапуск при входе в систему.
- MPRIS и системные медиаклавиши (Linux/Windows/macOS).
- Deep links `lumen://`.
- Discord Rich Presence с настраиваемым Application ID.
- Last.fm: now playing и scrobble, подключение через API key/secret.
- Эквалайзер (10 полос, пресеты) и нормализация громкости через mpv.
- Тексты песен из LRCLIB с подсветкой текущей строки.
- Скачивание треков через yt-dlp с прогрессом.
- Инфраструктура проверки и установки обновлений (в 0.2.0 автообновление отключено).
- Реальный раздел «Хранилище»: кэш, путь, папки, папка загрузок.

### Сборка

- Версия берётся из `package.json`; добавлен `scripts/bump-version.mjs`.
- CI для фронтенда и Rust.
- Release-workflow: Linux (AppImage/deb/rpm) и Windows (NSIS/portable), `SHA256SUMS`. Генерация `latest.json` и подписей временно отключена.
